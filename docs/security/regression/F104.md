| F104 (http-join-host-forwarded) | An HTTP mill command is marked as the office host (`host=True`, the installer join that skips the door) only when the TCP peer is loopback and the request carries no `X-Forwarded-For`, the same rule as /ws. A request through a proxy (the installed nginx edge proxies from loopback and always sets the header) is never the host, so an unauthenticated `POST /mill/v1/join` with any forwarded address, `127.0.0.1` included, is refused with SESSION_JOIN_DENIED at an invite, directory or iam door and mints nothing. This also holds when uvicorn trusts every proxy (`FORWARDED_ALLOW_IPS=*`) and rewrites the peer to a forged leftmost `127.0.0.1`. A direct loopback join with no header still joins as the host; a remote peer never does (#730). | `guard.mark_host(forwarded=)`, `middleware._do_POST_inner`, `rpc._require_join_authorized` | `tests/server/test_http_join_host_forwarded_730.py` (all cases), `tests/server/test_sec_join_gating.py` |
