| F106 (asgi-body-cap) | The ASGI wall reads at most `BODY_MAX_BYTES` (256 KiB) of a request body, and it checks the size before it reads. A declared `Content-Length` over the cap gets 413 before one body byte is read; a `Content-Length` that is not a number gets 400. A body with no length (chunked) is read through the stream with a running count and refused with 413 as soon as it passes the cap, so an unauthenticated `POST /mill/v1/join` or `/api/mill/join` (mill command paths skip the Wall IP allow-list) can no longer stream megabytes into memory. The largest real request (a 4096-character todo or letter field, JSON-escaped at up to 12 bytes a character) still reaches the handler (#747). | `asgi.BODY_MAX_BYTES`, `asgi._read_body_capped`, `asgi._dispatch_inner` | `tests/server/test_asgi_body_cap_747.py` (all cases), `tests/server/test_asgi.py` |
