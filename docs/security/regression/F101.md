| F101 (wall-static-cache-pins) | A Wall static file asked for with exactly one safe `?v=` pin (1 to 64 of `A-Z a-z 0-9 . _ -`) is sent with `Cache-Control: public, max-age=31536000, immutable`, since that URL never changes. Every unpinned file, an empty or odd pin, or a repeated `v` keep `public, max-age=60`; the door-gated page (`/`, board HTML) is `private, max-age=60` with `Vary: Cookie` (F115), so a new pin or an edited unpinned file is picked up within a minute. Every static file carries a content `ETag`; a matching `If-None-Match` gets 304 with the same headers, a stale one gets 200. The glance `static_cache` field names both policies. The file is read only when its real path sits under a static root (`_read_static`) (#712). | `middleware._static_cache_control`, `_static_etag`, `_read_static`, static branch of the wall handler, `glance` | `tests/server/test_wall_static_cache.py` (all cases), `tests/server/test_glance.py` |
