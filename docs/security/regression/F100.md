| F100 (door-ip-forwarded) | On `door=ip` the wall reads `X-Forwarded-For` only when the TCP peer is a trusted proxy (default this host's loopback, the installed nginx edge; `AGENT_COORD_TRUSTED_PROXIES` IPs/CIDRs replace it, `none` trusts none). From a trusted proxy the hops are read right to left and the first hop that is not a proxy is the client, so a spoofed left entry is never used. A private or other untrusted peer is judged by its own address whatever the header says: a private peer sending `X-Forwarded-For: 127.0.0.1` or an allow-listed address gets 403 when the peer is not on `wall-allow.txt`. A forwarded loopback address is not this machine: it passes only when it is on the allow list. A direct loopback connection with no header still passes. Path and directory doors are unchanged (#651); the human Wall ACL and the glance keypad read the header the same way since #731 (F105). | `allow.door_client` / `trusted_proxies` / `allowed(forwarded=)`, `asgi._dispatch_inner` door gate | `tests/server/test_door_ip_forwarded_651.py` (all cases), `tests/server/test_allow.py`, `tests/install/test_door_ip.py` |
