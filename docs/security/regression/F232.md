| F232 (wake-retry-backoff) | A failed desk wake (timeout, connection error, 408, 429, or 5xx) retries off the request with full jitter from 5 seconds, doubling, capped at 10 minutes, for about 1 hour. Each retry posts the same idempotency key and the same lease. A 401 or a 404 does not retry. A drained queue or a newer success stops the retry. One line names the desk, the attempts, and the last status when the waits end. No new command (card 827). | `server/wake.py` | `tests/server/test_wake_retry_827.py` (all cases) |
