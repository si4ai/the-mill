| F120 (todo-claimed-at) | `todo.claimed_at` is the time a card became claimed or its volunteer changed: `claim`, `claim --take-over`, `assign` and a `pass --back` that puts a card back to claimed stamp it; a note, an eta, an edit or a second `claim` by the same desk keep it; `unclaim`, `pass` and `pass --done` clear it (NULL whenever the card is not claimed). `mill_todo_update` sets it first in its SET list so it reads the old status and volunteer. In `mill connected` the claimed cards another desk watches (waiting on it) take their age and their newest-first order from `claimed_at`, never from `todo.updated`, so a note does not make a card look new. On an existing book `migrate.ensure()` adds the column and backfills every claimed card that has none from the volunteer's watcher row on the card (its first write there: the claim, or the create for a card it filed), capped at `todo.updated`, else `todo.updated`; cards that are not claimed stay NULL. A second ensure changes nothing and a run killed after the ALTER converges (card 821, #818).
