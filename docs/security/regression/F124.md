| F124 (wake-row-first-ring-on-leave) | A hint or letter is in the desk's push queue before the wall rings or sends it (#832). `emit` and `fanout` put the row as `missed` first, then read whether the desk sits: a live frame that reaches a socket marks that row `sent` (`_broadcast` -> `_settle_row` -> `rec_push.mark`), a raised send marks it `error`, a webhook desk gets `post_desk`. A woken desk whose connect runs before the POST returns finds the row on its sync line. `post_desk`'s `wake.pending` is the queue size (the item is already in it). When the desk's last socket leaves, or a live frame finds no socket, `ring_waiting` rings an armed desk that is not sitting and has a `missed` or `error` hint or letter (receipts never ring), with that row's frame and poke key, through `post_desk`'s window, wake_on and URL checks; it logs `reason=leave` or `reason=unsent`.
