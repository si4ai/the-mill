| F78 (sdist-repro) | The release wheel and sdist are byte-reproducible: two builds of one commit with the hash-locked `build.txt` tools and `SOURCE_DATE_EPOCH` set to the commit time give the same sha256 for both files, whatever the checkout path, umask, file mtimes, build time or build user. The in-tree backend `build_backend/mill_build.py` (`[build-system]` in `pyproject.toml`) runs `setuptools.build_meta`, then rewrites both archives with unchanged member bytes: every mtime `SOURCE_DATE_EPOCH`, files 0644 (0755 with an execute bit) and directories 0755; the sdist also gets members in name order, owner 0/0 with empty names, no PAX records, and a gzip header dated `SOURCE_DATE_EPOCH` with no file name; the wheel keeps its member order. A link or other special sdist member fails the build, and a second rewrite changes nothing. `tools/check_repro.py dist` clones the commit twice under umask 022 and 002, a second apart, builds each, and fails unless both match `dist/`; `build_pack` and release `verify` run it.
