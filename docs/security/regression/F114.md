| F114 (oidc-state-nonce-pkce) | A directory or iam Wall login is bound to the browser that started it. The login redirect sets a fresh random state, nonce and PKCE verifier in a ten-minute HttpOnly SameSite=Lax cookie scoped to `/mill/oidc/callback`, and sends state, nonce and an S256 `code_challenge` to the issuer. The callback trades no code unless `?state=` matches the cookie, sends the cookie's `code_verifier` to the token endpoint, and seats nobody unless the returned id token verifies and carries the login nonce; on success it clears the login cookie. A callback with no login cookie, a mismatched or missing state, or a token without the nonce sets no session (card 748). | `door.login_redirect`, `door.complete_login`, `/mill/oidc/callback` in `_do_GET_inner` | `tests/server/test_oidc_state_748.py` |
