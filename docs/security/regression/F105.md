| F105 (wall-glance-trusted-proxy) | The human Wall ACL (`wall-allow.txt` on path, directory, invite and iam doors), the glance keypad lockout and the glance station read `X-Forwarded-For` through `allow.door_client`, the same trusted-proxy rule as door=ip (F100). A private or loopback peer that is not a trusted proxy is judged by its own address: a forged allow-listed or `127.0.0.1` forwarded address gets the ACL 403, and six wrong keypad taps with six forwarded addresses lock the peer out, so the right taps are then refused. From a trusted proxy the client is the last hop that is not a proxy, so a spoofed left entry neither passes the ACL nor moves the lockout bucket, another client behind the same proxy is not locked out, and a forwarded loopback address passes the ACL only when it is on the list. A direct client sees no change, and an empty list still leaves the human Wall open. `allow.client_ip`, which read the first hop from any private peer, is gone (#731). | `allow.door_client`, `asgi._dispatch_inner` Wall ACL, `middleware._glance_tap`, `glance.accept_tap` / `client_bits` | `tests/server/test_wall_glance_trusted_proxy_731.py` (all cases), `tests/server/test_allow.py`, `tests/server/test_door_ip_forwarded_651.py`, `tests/server/test_glance.py` |
