| F-tw-command-word (tw-command-word) | A tw start hop stores a command word: the program basename, with one trailing exe suffix removed, in lower case, and one subcommand word only for git, gh, mill, rco, pip, npm, docker, uv, or cargo when that word is next. python, python3, and py with -m use the module. A flag, a path, or any other argument is left off. A bad word is omitted. On a nonzero exit or a crash, tw prints one stderr count line when the office reply errors.count is above 1, and prints errors.next on the next line when it is one plain sentence. A zero exit does not wait, and a missing errors object prints nothing. | `tw.protocol.command_word`, `tw.proc.run_argv`, `tw.link` event hop | `tests/client/test_tw_cmd_1303.py` (all cases) |
