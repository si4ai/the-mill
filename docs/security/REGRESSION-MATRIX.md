Add a row when a security fix lands; keep rows free of exploit detail beyond
what the linked test needs.

Rows live in `docs/security/regression/<ID>.md` (one file per row). This
file is generated - run `python tools/regression_matrix.py write` after
adding or editing a row file. Do not append rows here by hand (card 924).
