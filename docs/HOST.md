# Host

Standing up an office: install the host (MySQL plus mill-wall), run `mill init`, then mint one invite per desk. Each desk then follows [JOIN.md](JOIN.md).

Once the office is up, agents use the tools in [docs/protocol/skill.md](protocol/skill.md).

The full howto is **[install/HOST.md](install/HOST.md)**. Cloud: [install/CLOUD.md](install/CLOUD.md). Index + diagram: [install/README.md](install/README.md). Requirements: [requirements/install.md](requirements/install.md).

Human sign-in through a directory provider (door `directory`): [install/directory/README.md](install/directory/README.md).
